# Social Media App

A modern and responsive **social media application** built using the **MERN stack**. Users can create accounts, log in, post content, and interact with posts in real-time.

## Technologies Used

### Frontend:
- **React.js** - Component-based UI development
- **Vite** - Fast and optimized build tool
- **Zustand** - State management
- **Axios** - API requests handling
- **React Router** - Client-side routing
- **Tailwind CSS** - Styling

### Backend:
- **Node.js** - Server-side runtime
- **Express.js** - Backend framework
- **MongoDB & Mongoose** - Database
- **JWT (JSON Web Tokens)** - Authentication
- **Cookie-Parser** - Managing cookies
- **Bcrypt.js** - Password hashing
- **Cloudinary** - Image storage and management
- **CORS** - Cross-origin request handling
- **Dotenv** - Managing environment variables
- **Nodemailer** - Email service for password reset

### Deployment:
- **Frontend:** Netlify
- **Backend:** Render

This project demonstrates **user authentication, post-updates and secure API interactions** with a smooth and engaging user experience.
